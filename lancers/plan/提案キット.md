# ランサーズ 提案・メッセージ キット（sabato）

作成日：2026年11月5日
対象：ランサーズで提案（応募）を送る人（毎日提案を送っているPC上のClaudeセッションも含む）

---

## 0. 最初に読むこと

### このキットのねらい
これまでに約130件以上提案を送って、受注はごく少ない状態です。送る数を増やすより、**「選ぶ案件」「1行目」「最初の一歩」**を変えて、1件あたりの受注率を上げます。

### 使う順番
1. 案件を「1. 選び方」の足切りとスコア表で採点する → **6点以上だけ応募**
2. 「3. テンプレート」から近いものを選び、【 】をすべて埋める
3. 1行目と最後の質問は、毎回その募集文の言葉で書き直す
4. 「2-4 送信前チェック」を通してから送る
5. 「1-5 応募記録」に1行残す

### 書いてよい実績（これ以外は書かない）
- 経理実務10年（記帳、月次決算、試算表の作成など）
- ランサーズで、Excel・Microsoft 365 Copilot を使った業務効率化や資料作成の仕事を受注・納品した実績（例：Copilotの業務検証を支援し、手順書・比較表・報告スライドを納品）
- 日本の上場企業にメールで取材し、noteで記事を公開している
- 日本株をテーマにしたKindle本を出版している（例：『日本株「テンバガー」発掘の教科書』）
- 見本：企業分析レポート（上場企業のタナベコンサルティンググループを題材にしたサンプル、A4・4ページ）、取引先財務チェックシート（1ページ）、Excelひな形（資金繰り表・財務診断・上場企業比較表・仕訳帳）
- 屋号「日本個別株デューデリジェンスセンター」は、企業調査・上場企業の案件でだけ使う（Excelや記帳の案件では、名前だけのほうが伝わりやすい）

### 書かないこと
- 資格（税理士・公認会計士・行政書士・FPなど）。「税理士事務所レベル」「会計士並み」のような、資格があると誤解される表現も書かない
- 件数・満足度・リピート率など、確認できない数字
- 「必ず」「絶対」「完璧」「No.1」「業界最安」「劇的に」など、根拠のない強い表現

### 規約で守ること（ランサーズ）
- 契約前に、メールアドレス・電話番号・住所・LINE・Chatwork・SNSのアカウントを**書かない・聞かない**。ZoomなどランサーズのWebサイト外での打ち合わせも提案しない
  - 利用規約では、電話番号や住所などの個人情報の発信、内容を明確にしないままサイト外へ誘導すること、サイトを通さない直接取引とその勧誘が禁止されています
- 添付ファイル（見本PDF・画像）にも、連絡先・外部URL・QRコードを入れない（ランサーズは、添付ファイルを使ったサイト外への誘導に注意を呼びかけています）
- 見本は、ランサーズの中（プロフィールのポートフォリオ、パッケージの画像、提案への添付）で見せる
- noteのURLは、募集文で「実績のURLを書いてください」と求められたときだけ書く。書く前に、noteのページにメールアドレスやSNSのDMの案内が載っていないか確認する
- 評価について、見返り（値引き・おまけ）を示してお願いしない。「高評価」「星5」など、評価の中身を指定しない
- 相手から外部の連絡先を求められたら、「5-10 断り方」の文で丁寧に断る

### 事前準備（1回だけ）
- [ ] ポートフォリオに見本を登録する：企業分析レポート（4ページ）、取引先財務チェックシート、資金繰り表・財務診断・上場企業比較表・仕訳帳のExcel画面の画像、Excel自動化の「作業の前と後」の画像
- [ ] 見本のファイル・画像に、連絡先・外部URL・QRコードが入っていないか確認する
- [ ] パッケージA〜Fを公開する（公開前は、テンプレートの「パッケージ『〜』」の一文を削る）
- [ ] プロフィールの一言をパッケージとそろえる（例：「経理実務10年｜決算書・財務の数字を読み解く経理のプロ」）

## 1. 応募する案件の選び方

### 1-1 足切り（1つでも当てはまれば、点数に関係なく応募しない）

**時間・働き方**
- [ ] 平日の日中（例：9〜18時）の作業・電話・定例会議・チャットの即時返信が「必須」になっている
- [ ] 出社・常駐、または決まった時間の稼働（シフト制）が必要

**資格が必要な業務が中心**
- [ ] 税務申告書（確定申告書・法人税の申告書など）の作成・提出、税務の相談、年末調整の税額の判断 → 税理士の業務
- [ ] 監査、決算書が「適正である」ことの証明 → 公認会計士の業務
- [ ] 補助金・許認可など、官公署に出す申請書の作成・提出の代行 → 行政書士の業務
- [ ] 社会保険・労働保険の届出書類の作成・提出 → 社会保険労務士の業務
- [ ] 契約書の作成・チェック、トラブルの交渉 → 弁護士の業務
- [ ] 特定の人に向けた株式の売買の助言、銘柄のおすすめ → 投資助言（金融商品取引法の登録が必要）

**規約・安全面**
- [ ] 契約前に、LINE・メール・Chatworkなど、ランサーズの外での連絡を求めている
- [ ] 提案の時点で、本名・住所・電話番号など詳しい個人情報を書くよう求めている
- [ ] 契約前の無償のテスト作業、外部サイトへの登録、初期費用、教材の購入を求めている
- [ ] 「誰でも簡単」「スキマ時間で高収入」など、副業の勧誘に見える
- [ ] 知らない実行ファイルのダウンロードや、外部サイトでのパスワード入力を求めている

### 1-2 応募すべき案件のサイン
- 経理・Excel・財務・上場企業の調査・Copilot活用のどれかが中心になっている
- 作業内容・納品物・期限が具体的に書かれている（例：「毎月300行の銀行CSVを弥生会計の取込形式にしたい」）
- 予算が「4-2 価格の目安表」の金額以上、または近い
- 依頼者の評価が良く、発注率がある程度高い（目安：50%以上）。本人確認が済んでいる
- 掲載からあまり時間がたっておらず（目安：48時間以内）、提案数が少ない（目安：10件未満）
- 毎月続く仕事になりそう（記帳、月次の集計、資金繰り表の更新、月次レポートなど）
- 平日夜と土日の作業で、納期に無理なく間に合う（目安：小さな作業でも3日以上）

**優先する順番**（経理10年の経験が一番効くものから）
1. 記帳・会計ソフト取込・資金繰り表・財務分析・上場企業の調査
2. 経理まわりのExcel自動化（集計・転記・請求書・精算書）
3. Copilot/ChatGPTの業務活用（実績があるもの）
4. 一般的な資料作成・データ入力（応募が多く差がつきにくいので、点数が高いものだけ）

### 1-3 注意して判断する案件（応募するなら書き方に気をつける）
| 案件の特徴 | どうするか |
|---|---|
| 会計ソフトに直接入力してほしい | 取込用CSVでの納品、またはメンバーとして招待してもらう方法を提案する。ID・パスワードはそのまま預からない |
| 「事業計画書」「補助金の書類」 | 数値計画のExcelだけなら応募可。提案文に「申請書そのものの作成・提出の代行はしない」と1行書く |
| 「株式の分析」「銘柄の調査」 | 公開資料の整理・要約は可。売買のおすすめ、目標株価、「買いかどうか」の判断は書かない・受けない |
| 公表前の決算資料を扱う（決算説明資料など） | 内容を外に出さない、その会社の株式を売買しない、noteで触れない（インサイダー取引の規制に注意） |
| マイナンバー・給与・個人の口座を含むデータ | 受け渡しと削除の方法を、契約前にメッセージで確認する |
| 新しい依頼者（評価0件） | 依頼内容が具体的なら応募可。あいまいなら見送り |
| Mac版Excelでのマクロ | 動く環境を確認してから。分からなければ質問を1つ目にする |
| 提案数がすでに30件以上 | 1行目で他と差がつけられる（経理10年が効く）場合だけ |
| コンペ方式（採用された人だけ報酬） | 原則見送り。時間を使っても報酬がないことが多い |
| タスク方式の単純作業 | 原則見送り。単価が低く、評価にもつながりにくい |

### 1-4 10点満点のスコア表

| 項目 | 2点 | 1点 | 0点 |
|---|---|---|---|
| ① 得意分野と合うか | 記帳、会計ソフト取込、資金繰り、財務分析、上場企業の調査、経理Excelの自動化 | Excel一般、GAS、Copilot/ChatGPT、資料作成、経理系のデータ入力 | 上のどれにも当たらない（**0点なら応募しない**） |
| ② 予算 | 目安表の金額以上（作業時間で割って1時間2,500円以上） | 目安表の7割以上（1時間2,000円以上）、または「予算は相談」で内容が具体的 | それより低い |
| ③ 依頼者 | 評価が良く（目安：★4.5以上）、発注率50%以上、本人確認済み | 新しい依頼者、または発注率30〜49% | 発注率30%未満で募集が多い、評価に「連絡が途絶えた」などの悪い傾向がある |
| ④ 競争 | 掲載から48時間以内、かつ提案数10件未満 | 提案数10〜29件、または掲載から3〜5日 | 提案数30件以上、または締め切り直前で提案が多い |
| ⑤ 条件 | 作業内容・納品物・期限が具体的で、平日夜・土日の作業で納期に間に合う | どちらかがあいまい（質問すれば分かりそう） | 内容がほとんど書かれていない、または納期が厳しい |

**判定**
- 8〜10点：すぐ応募する（その日のうちに、いちばん丁寧に書く）
- 6〜7点：応募する（テンプレートを使い、1行目と質問を募集文に合わせる）
- 0〜5点：見送る

**数のめやす**：1日の応募は3〜5件までにします。減らした分、1件に15〜20分かけて、1行目・進め方・質問をその案件に合わせます。

**採点の例**
「毎月の銀行明細CSVを弥生会計に取り込める形にするExcelマクロ／予算1〜3万円／依頼者 ★4.8・発注率70%／掲載1日目・提案数6件／納期2週間」
→ ①2点 ②2点 ③2点 ④2点 ⑤2点 ＝ **10点（すぐ応募。テンプレートT02）**

「Excelでの資料作成。平日10〜17時はチャットにすぐ返信できる方／予算5,000円」
→ 足切り（平日日中の即時返信が必須）＝ **応募しない**

## 2. 勝てる提案文の型

### 2-1 構成（全体で300〜600字）

| 順番 | 書くこと | ポイント |
|---|---|---|
| 1行目 | 依頼の核心の言い換え | 「【何を】【どうしたい】、というご依頼と理解しました。」依頼者の言葉と目的を入れる。提案の一覧で最初に目に入る部分なので、挨拶より先に書く |
| 2行目 | 自己紹介1行 | 「経理実務10年のsabatoです。」＋この案件に関係する経験をひとこと |
| 進め方 | 3行（①②③） | ① 最初の一歩（小さく・早く・確認できるもの）② 本作業 ③ 確認と納品。すべて「ご契約後」の作業として書く |
| 実績・見本 | 1〜2個 | この案件に関係するものだけ。関係するパッケージか見本を1つだけ示す |
| 金額と納期 | 1〜2行 | 金額・日数・内訳か根拠を1行。作業時間（平日夜・土日）と返信の目安を書く |
| 質問 | 1つだけ | 答えやすく、答えると見積もりが正確になる質問 |

### 2-2 書き方のコツ
- 募集文の言葉をそのまま使う（「毎月の転記」と書かれていたら、こちらも「毎月の転記」と書く）
- 「できます」より「こうします」と書く
- 数字は依頼者の情報から使う（件数・シート数・期間）。分からない数字は「【 】件と仮定して見積もりました」と書く
- 募集文に「提案時に書いてほしいこと」があれば、型より先に全部答える
- 長い挨拶、経歴の並べ書き、「丁寧・迅速・誠実」は削る
- 平日の日中に作業できないことは、隠さずに「返信の目安」として先に書く（あとで困らせない）
- 資格が必要な部分がからむ案件は、「〜は行いません」を1行だけ、責める調子にならないように書く

### 2-3 NG例 → OK例の書き換え（3組）

#### 1組目：Excel集計の自動化

金額：10,000円／納期：ご契約から4日
作業は平日夜と土日に行い、メッセージには原則24時間以内に返信します。

1点だけ教えてください。各ファイルの列の並びは、毎月同じでしょうか？

freeeへは、取込用のCSVでお渡しする方法と、メンバーとして招待いただいて入力する方法の、どちらがご希望でしょうか？

#### 3組目：Copilotの業務活用

**NG例**
```text
Copilotに詳しく、業務効率化の実績も多数あります。御社の業務を劇的に改善し、作業時間を必ず半分にします。まずはZoomで1時間ほどお打ち合わせさせてください。平日の昼間でも調整いたします。

3. 試した結果（できたこと・注意点）を1枚の比較表にして、手順書と一緒に納品します

金額：30,000円／納期：ご契約から10日
作業は平日夜と土日です。やり取りはランサーズのメッセージで進めます。

1点だけ教えてください。TeamsとOutlookで、Copilotが使える状態になっていますか？
```

### 2-4 送信前チェック
- [ ] 1行目に、募集文の言葉（作業の名前・対象・目的）が入っている
- [ ] 【 】がすべて埋まっている（埋められない＝募集文を読み切れていないサイン）
- [ ] 進め方が3行で、最初の一歩が具体的。すべて「ご契約後」の作業になっている
- [ ] 実績は「0. 書いてよい実績」の範囲だけ。資格・誇張した数字がない
- [ ] パッケージか見本を1つだけ示した（公開前のパッケージ名は書いていない）
- [ ] 金額と納期が、提案フォームの欄と本文で一致している（税込・税抜の表記も欄に合わせる）
- [ ] 平日夜と土日の作業だけで、納期に間に合う
- [ ] 質問は1つだけ
- [ ] 連絡先・外部URL・外部ツールでの打ち合わせの提案がない（添付ファイルの中も）
- [ ] 資格が必要な部分は、受けると書いていない（必要なら「行いません」を1行）
- [ ] 募集文で指定された項目（実績・稼働時間など）に、すべて答えた
- [ ] 600字前後に収まっている

## 3. 案件タイプ別の提案テンプレート（16本）

### 使い方の注意
