# ランサーズ プロフィール一式と、信頼を早くつくる計画

打ち出し方：**「経理実務10年 × 財務の数字を読むプロ」**（新パッケージA〜Fと同じ打ち出し）
日本株・金融ライティングはクラウドワークス側の主役です。ランサーズでは「公開資料を読み慣れている裏付け」として、控えめに使います。

- 【　】のところは、ご自身で埋めるか、確認してほしい箇所です。
- 資格は書いていません。確認できていない実績・件数・数字も書いていません。
- 欄の名前・文字数の上限は、ランサーズの編集画面に合わせてください（上限は公開情報では確認できませんでした）。
- 作業開始日は、KPIシート（`growth/kpi/ランサーズKPIシート.xlsx`）とそろえて **2026年11月9日（月）＝第1週** としています。

### 0-4. 検索で上に出るしくみ（表示順）

ランサーズは「不正防止のため具体的な基準は公開していない」としています。公表されている「指標の種類」は次のとおりです。

- **パッケージの検索順位** [27]
  - パッケージ側：表示数、閲覧数、お気に入り数、相談数と注文率、注文数と完了率、評価、返信速度、出品内容の鮮度と充実度（タイトル・画像）、価格、プランの有無
  - ランサー側：本人確認の有無、ランク、実績と完了率、評価、プロフィールの充実度、ポートフォリオ、資格
- **「フリーランスを探す」の検索順位** [28][29]
  - 2023年11月から「ポートフォリオの指標」が加わった：表示数、閲覧数と読了率、お気に入り数と率、内容の鮮度と充実度（タイトルの具体性、ファイルの数、説明文、検索キーワードとの一致）
  - 2026年3月をめどに「活発に活動しているランサーが正しく評価される」方向へ調整する予告。実績や金額の目安をプロフィールに書くと受注につながりやすい、とも案内 [30]（切り替えが済んだかは未確認）
- **ランサーズ自身の受注のコツ** [31][32][33]：画像付きのパッケージは相談されやすい／業種・ツール別に出品を分けると「自分向け」と感じてもらいやすい（ただし中身がほぼ同じ複製を大量に作ると出品取り消しの場合あり [34]）／検索結果の少ないキーワードは1ページ目に出やすい／アナリティクスを見ながらタイトル・サムネイルを直す
- **ランサーズチョイス（パッケージのおすすめバッジ）**：実績と良い評価が最低条件。定期的な編集などのメンテナンスも大切。基準は非公開 [35]
- **パッケージ広告**：検索1ページ目の広告枠。1回5,000円（税抜）で最大1,000回表示または30日間。ブロンズ以上 [36]（料金・条件が今も同じかは未確認）

### 0-6. パッケージの管理

- 出品したパッケージは**削除できない**。公開設定を「非表示」にすると一覧とプロフィールから見えなくなる [48]
- 「出品管理」の各パッケージの「…」から「アナリティクス」を見られる。誰がどのパッケージを見たかも確認できる [32][49]（**見られる項目の一覧は未確認**）
- 「出品管理」から複製できる。複製したらタイトルとサムネイルは変える必要がある [34]
- 「営業自動メッセージ」：プロフィールやパッケージを一定時間見たクライアントに、登録した文面が自動で届く。1人のクライアントが1日に受け取れるのは3件まで、過去にやりとりがある相手などには届かない [49][50]

```
1．経理実務10年
記帳・月次決算・試算表の作成を実務で担当してきました。決算書を「作る側」の目線で、数字が動いた理由まで読み解きます。

上場企業へのメール取材をもとにした記事をnoteで公開し、日本株をテーマにしたKindle本も出版しています。

4．Excel・資料まで仕上げます
ランサーズでは、Excel・Microsoft 365 Copilotを使った業務効率化や資料作成のお仕事を受注・納品してきました（例：Copilotの業務検証を支援し、手順書・比較表・報告スライドを納品）。

1．ご購入の前に、目的・ご用意いただく資料・納期をメッセージで確認します。
2．作業中に判断が必要な点は、まとめてご質問します。
3．納品後のご質問にも、プランに応じてお答えします。

・税務申告書の作成・提出、税務相談（税理士の業務）
```

- タイトル：事業会社での経理実務（約10年）
- 雇用形態：【正社員など】／期間：【　年　月】〜【　年　月】


### 3-2. 入口価格の使い方

- 入口にするのは、**A ベーシック10,000円（3日）**、**B ベーシック10,000円**、**E ベーシック10,000円**、1〜3月は **F ベーシック10,000円**。10,000円は、ランサーズのパッケージの最低出品価格です [51]。ベーシックは、評価を集めるための入口です。

- [ ] プランの範囲（ページ数・社数・工程数・仕訳数）と納期を、メッセージで確認済み
- [ ] お受けできない内容（税務申告・申請書類・投資助言・監査証明・契約書）が入っていない

**中身**
- [ ] 数字はすべて元の資料と2回照合した（転記ミスがない）
- [ ] 単位（円・千円・百万円・億円）と期（〇年〇月期）を表の見出しに書いた
- [ ] 自分で計算した指標には、計算式か「作成者が算出」と注記した
- [ ] A・B・C：数字ごとに出典（資料名・ページ）を書いた
- [ ] A・C：「保証するものではない」「投資助言ではない」の注意書きを入れた
- [ ] F：科目に迷うものは自分で決めず「要確認」リストにした。合計が通帳・明細と合っている
- [ ] D：実績の月末残高が通帳と一致している。予定の前提（入金日など）を書いた
- [ ] E：テスト用データで動かした。元データを壊さない（バックアップを取る）。Windows版Excelで確認した
- [ ] 専門用語には、ひとこと説明を付けた
- [ ] 誤字・脱字、会社名・証券コードの表記を確認した

**ファイル**
- [ ] Excelに「#REF!」「#DIV/0!」などのエラーがない。入力するセルは色分けした
- [ ] ファイル名は「日付_内容」（例：20261120_取引先財務チェック_〇〇社.pdf）
- [ ] PDFは開いて見た目を確認（スマホでも）
- [ ] E・D（スタンダード以上）：手順書を付けた

**納品メッセージ**
- [ ] 要点を3行で書いた／ファイルの一覧と見方を書いた
- [ ] 質問を受け付ける回数・期限を書いた
- [ ] お預かりした資料を削除する予定日を書いた
- [ ] 納期の前日までに納品できた（遅れそうなときは、分かった時点で連絡）

### 3-5. 評価をお願いするタイミング

ランサーズの流れは「納品 → お客さまの確認（検収）→ 支払い確定 → お互いに評価」です [39]。

| タイミング | すること | 文面の例 |
|---|---|---|
| 納品時 | 内容の確認をお願いする（評価にはふれない） | 「納品物をお送りしました。内容をご確認いただき、気になる点があれば【　日】までにお知らせください。問題がなければ、検収のお手続きをお願いいたします。」 |
| 支払い確定の当日 | **自分から先にお客さまを評価**し、お礼を送る | 「このたびはご依頼いただき、ありがとうございました。こちらからも評価をお送りしました。お手すきの際に、今回のお取引についてご評価いただけますと、今後の改善の参考になります。納品物について気になる点があれば、【　月　日】までお気軽にご連絡ください。」 |
| その後 | **くり返し催促しない** | 評価が付かなくても追いかけない（期限が過ぎた場合の扱いは未確認 [41]） |

### 3-6. リピートのつくり方

- **次の使い道を1回だけご案内**（納品時か、時期が来たとき）
  - A：「次の決算発表のあと、同じ形式で更新できます」（3月期決算の会社は、第3四半期の発表が1月末〜2月中旬に多い）
  - B：「来期の決算が確定したら、4期分で更新できます」／「資金繰り表（D）とあわせると、お金の動きまで見えます」
  - C：「比較する会社の追加や、項目の追加もできます」
  - D：「毎月の更新をお手伝いすることもできます」（継続の形）
  - E：「次に自動化できそうな作業がありました：【　】」
  - F：「来年は月ごとに記帳すると、申告前が楽になります。月次の記帳もお受けできます」
- **2回目は手間を減らす**：前回の形式・ひな形をそのまま使えるので、「2回目以降はご用意いただく資料が少なくて済みます」と伝えます（評価とは関係なく、すべての方に同じ条件で）。
- **ランサーズの中で続ける**：継続の依頼もランサーズのメッセージとパッケージ・プロジェクトで受けます。直接取引には応じません [45][46]。
- **「残念」を防ぐ**：購入前の確認で、できること・できないことをはっきり伝えます。万一ミスがあれば、すぐに直して報告します。

## 4. 90日ロードマップ（週単位）と追う数字

### 4-1. 認定ランサーについての見通し

認定ランサーには「獲得報酬額がカテゴリの上位20%以内」があり、過去1年の実績で毎月審査されます [2]。小さな金額の注文だけでは届きにくく、**90日で認定ランサーになるのは難しい見込み**です（上位20%の金額は公開されておらず未確認）。
そこで90日の目標は次のとおりにします。

1. 認証4つ・プロフィールの全項目を完成（認定の「登録済み」条件を先に満たす）
2. 評価の「満足」を100%に保つ（認定・シルバーは95%以上）
3. 完了率を100%に保つ（認定・シルバーは90%以上）
4. ランク：レギュラー → ブロンズ（初受注）→ シルバーの条件に届く状態をめざす
5. 単価の高いプラン（スタンダード・プレミアム）の受注を増やし、報酬額の条件に近づく

## 5. 旧パッケージ約19件の整理

### 5-1. 前提

- パッケージは削除できません。「非表示」にできます [48]。非表示にしたものは、あとで公開に戻せます。
- 非表示にしたパッケージに付いていた評価が、プロフィール全体の実績にどう残るかは**未確認**です。
- 出品数そのものが検索に効くかは**未確認**です。ランサーズは業種別の出品をすすめていますが [31]、テーマのばらばらな出品は「何のプロか」を分かりにくくします。

### 5-2. 判断の基準

アナリティクスで、**同じ期間（例：直近90日）**にそろえて比べます。

| 見る数字 | 読み方 |
|---|---|
| 販売実績・評価 | 「信頼の資産」。あるものは原則として消さない |
| 閲覧数（表示数があれば 閲覧÷表示） | 検索で見つかり、クリックされているか。低いのはタイトル・サムネイルの問題 |
| お気に入り | 「検討中」のしるし。多いのに相談・購入がないのは、価格・説明・不安な点の問題 |
| 相談数 | 需要があるしるし |

判断の流れ

1. **相談中・取引中のものがある** → 取引が終わるまで触らない
2. **販売実績がある ＋ 経理・Excel・財務のテーマに合う** → **残す**。新パッケージ（A〜F）の内容に書き換えて「器」として使う（新しく作るより、閲覧・お気に入り・評価の積み重ねを生かせる可能性があるため。引き継ぎの仕様は未確認）
3. **販売実績がある ＋ テーマに合わない** → 新パッケージが見られ始めるまで（2〜4週）**残して表示順を一番下へ**。その後、閲覧が少なければ非表示
4. **販売実績がない ＋ テーマに合う** → 新パッケージと内容が重なるなら**統合**（数字の良いほうを器にして、もう一方を非表示）
5. **販売実績がない ＋ テーマに合わない** → **非表示**
6. 内容がほぼ同じものが2つ以上 → 1つにまとめる（同じ内容の大量の複製は取り消しの対象になりうる [34]）

### 5-3. 旧パッケージの行き先（初めの見立て）

実際の数字を見て、5-2の基準で決め直してください。

| 旧パッケージ | 受け皿 | 初めの見立て |
|---|---|---|
| 記帳代行 | F | 統合（実績があれば F の器に） |
| Excel集計 | E | 統合 |
| PDF→Excel | E | 統合 |
| 会計ソフト取込 | E（または F） | 統合 |
| 経費精算書 | E | 統合 |
| スプレッドシート | E | 統合（Googleスプレッドシートは E で「事前にご相談」） |
| 資金繰り表（今ある出品） | D | 残す → D の内容に書き換え |
| 見積書・工程表 | なし | 非表示（実績があれば 5-2 の3へ） |
| 講座資料スライド | なし | 非表示（同上） |
| 電子書籍化 | なし（クラウドワークス側で扱う） | 非表示（同上） |
| 受講者管理表 | E | 非表示か統合 |
| 告知文 | なし | 非表示 |
| Copilot・業務効率化（あれば） | E の近く | 実績があれば残す |
| その他【　】 | 【　】 | 【　】 |

### 5-4. 作業の手順

1. **記録**：「出品管理」の一覧をスクリーンショットで残す（あとで戻せるように）
2. **棚卸し**：各パッケージの「…」→「アナリティクス」で、期間をそろえて数字を下の表に写す（KPIシートの「パッケージ別」と同じ項目）
3. **判定**：5-2の流れで「残す・統合・非表示」を決める
4. **器を決める**：新パッケージA〜Fのうち、まだ公開していないものは、テーマの合う旧パッケージ（数字が一番良いもの）を書き換えて使う
5. **書き換え**：タイトル・サムネイル・説明文・3つのプラン・カテゴリ・業種を、`lancers_packages.md` の文面に差し替える（カテゴリを後から変えられるかは未確認）
6. **非表示**：「…」→ 公開設定 →「非表示」
7. **表示順**：A → B → D → E → F → C（1〜3月は F を一番上に）
8. **そろえる**：自己紹介のA〜Fの名前・料金と、パッケージのタイトル・価格が一致しているか確認
9. **見直し**：2週間後と4週間後に数字を見て、非表示にしたものを戻すか決める
