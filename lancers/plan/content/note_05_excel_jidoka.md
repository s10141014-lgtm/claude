# note記事⑤ 経理のExcel作業を自動化する前に、整理しておくこと

## はじめに

毎月、同じ形のExcelをコピーして貼り付ける。銀行やカードの明細を、会計ソフトに取り込める形に並べ替える。部門ごとのシートを1つに集計する――。

経理の仕事には、「毎月同じことを、手で繰り返している作業」がたくさんあります。最近は、マクロ（VBA）だけでなく、ExcelのPower Query や Microsoft 365 Copilot など、作業を自動化したり手助けしたりする道具も増えました。

ただ、自動化は「今の作業を、そのまま機械に置き換えること」ではありません。作業の流れやデータの形が整理されていないまま自動化すると、ちょっとした変更で動かなくなったり、作った人しか直せない仕組みになったりします。

この記事では、経理の現場で10年働いてきた経験から、自動化の前に整理しておきたい6つのことをまとめます。

## 1. 今の作業を、すべて書き出す

最初にやることは、作業の棚卸しです。頭の中にある手順を、箇条書きで書き出します。

- 何の作業か（例：カード明細を会計ソフトの取込形式に変える）
- どのくらいの頻度か（毎日・毎週・毎月・年1回）
- 1回にかかる時間
- 元になるデータ（どこから、どんな形で来るか）
- できあがるもの（誰に渡すか、どこに取り込むか）
- 担当者

[図：作業の棚卸し表のひな形。列は「作業名／頻度／1回の時間／元データ／できあがるもの／担当／困っていること」。2〜3行だけ記入例を入れる]

書き出してみると、「この作業は、そもそも要らなかった」「2つの作業で同じ集計をしていた」と気づくこともあります。**自動化の前に、なくせる作業はなくす**。これが、いちばん手軽で効果の大きい改善です。

また、「頻度 × 1回の時間」で1年間の作業時間を出してみると、どの作業から手をつけるべきか、優先順位がつけやすくなります。

## 2. 元データの「形」をそろえる

自動化がうまくいくかどうかは、元のデータの形に大きく左右されます。集計しやすい表には、共通のルールがあります。

- 1行に1件のデータ（1つの取引）を入れる
- 見出しは1行だけにする
- セルの結合をしない
- 途中に合計の行や、空白の行を入れない
- 日付は日付、金額は数値として入力する（「1,000円」のように、単位を文字で入れない）

[図：集計しにくい表（結合セル・途中の小計・「円」付きの金額）と、集計しやすい表（1行1件・見出し1行）を左右に並べたビフォー・アフター]

見た目を整えた「報告用の表」と、集計のための「データの表」は、分けて作るのがおすすめです。データの表から報告用の表を作る流れにしておけば、自動化しやすくなります。

## 3. 名前と区分のルールを決める

同じ取引先なのに、「株式会社ABC」「(株)ABC」「ABC」と表記がばらばらになっていると、集計のたびに手で直す必要が出てきます。

- 取引先名の表記（正式名称にするか、略称にするか）
- 勘定科目や部門のコード
- 全角・半角、スペースの有無

こうしたルールを決めて、一覧表（「マスタ」と呼びます）にしておきます。自動化の仕組みを、このマスタを見て変換するように作っておけば、取引先が増えてもマスタに1行足すだけで済みます。

なお、勘定科目や消費税の区分を「どう判断するか」は、会社の経理のルールや、顧問の税理士さんの方針に沿って決めるものです。自動化は、**決めたルールを当てはめる作業を速くするもの**だと考えてください。

## 4. 「出口」の形を先に確かめる

作業の最後に会計ソフトに取り込むなら、**取り込むファイルの形式を最初に確認**します。

弥生会計、freee、マネーフォワード クラウドなど、主な会計ソフトにはCSVファイルなどでデータを取り込む機能があります。ただし、列の並びや日付の書き方、必要な項目は、ソフトごとに違います。ソフトの更新で形式が変わることもあります。

各ソフトのヘルプで最新の形式を確認し、そこから逆算して自動化の流れを考えると、手戻りが少なくなります。

## 5. 「自動にしない部分」を決める

すべてを自動にしようとすると、仕組みが複雑になります。むしろ、**人が確認する部分をはっきり決めておく**ほうが、安心して使える仕組みになります。

- 科目の判断に迷う取引は、自動で処理せず「要確認」として一覧にする
- 処理の前と後で、件数と合計金額が一致するかをチェックする
- いつもと違う金額（極端に大きいものなど）に印をつける

[図：自動化の流れ図。「元データ → 変換（自動）→ チェック（件数・合計の一致、要確認の抽出）→ 人が確認 → 取込用ファイル」。人が関わる部分だけ色を変える]

経理の数字は、間違っていたときの影響が大きいものです。速さだけでなく、間違いに気づける仕組みにしておくことが大切です。

## 6. 保存のルールと、引き継ぎの方法を決めておく

自動化を考えるときは、データの「保存」にも目を向けておきましょう。

2024年1月から、メールやWebで受け取った請求書・領収書などの電子取引のデータは、原則として電子データのまま保存することが必要になっています（電子帳簿保存法）。また、2023年10月からはインボイス制度も始まっています。作業を自動化した結果、元のデータを消してしまった、ということがないように注意が必要です。具体的な保存の方法は国税庁の案内で確認し、判断に迷う場合は顧問の税理士さんに相談してください。

もう一つ大切なのが、**担当者が替わっても使えるようにしておくこと**です。

- 操作の手順書を作る（画面の画像付きだと伝わりやすい）
- 「元データを置く場所」と「ファイル名のつけ方」を決めておく
- うまく動かないときに確認するポイントを書いておく

作った人しか使えない仕組みは、その人がいなくなったときに、かえって手間を増やしてしまいます。

## 手段の選び方

整理ができたら、ようやく手段を選びます。目安は次のとおりです。

| 作業の性質 | 向いている手段の例 |
|---|---|
| 毎月決まった形の表を集計するだけ | 関数（SUMIFS など）、ピボットテーブル |
| 形の決まったCSVなどを取り込んで、整える | Power Query（Excelの「データの取得と変換」） |
| ボタン1つで、複数の手順を順番に実行したい | マクロ（VBA） |
| 手順書の下書きや、関数・集計の考え方の相談 | Microsoft 365 Copilot などのAI |

[図：上の表を、「作業の性質」から矢印でたどって手段にたどり着くフローチャートにしたもの]

高度な仕組みほどよい、というわけではありません。**担当者が理解して、自分で直せる範囲の手段を選ぶ**ことが、長く使い続けるコツです。

## まとめ

自動化の前に整理しておきたい6つのこと：

1. 今の作業をすべて書き出し、なくせる作業はなくす
2. 元データを「1行1件」の形にそろえる
3. 取引先名や科目などのルールを決めて、マスタにする
4. 会計ソフトの取込形式（出口）を先に確かめる
5. 人が確認する部分と、チェックの方法を決める
6. 保存のルールと、引き継ぎの方法を決めておく

この整理ができていれば、自動化の仕組みづくりはずっと進めやすくなります。まずは、今月の作業を書き出すところから始めてみてください。

## 経理のExcel作業の自動化をお手伝いしています

「整理まではできたけれど、仕組みを作る時間がない」「何から手をつければいいか、一緒に考えてほしい」という方に向けて、ランサーズで**「経理Excelの自動化（会計ソフト取込CSVまで）」**をご用意しています。

- 複数ファイルの集計、銀行やカードの明細CSVから会計ソフト（弥生会計・freee・マネーフォワード）の取込形式への変換、PDFの表の取り込みなどに対応します
- ベーシック（10,000円・4日）は1工程、スタンダード（24,800円・7日）は3工程まで（入力ミスのチェック機能付き）、プレミアム（49,800円・12日）は月次の一連の作業を1ボタンにまとめます
- マクロ付きExcelと操作の手順書で納品します。会計ソフトのIDやパスワードの共有は不要です

ランサーズでは、Excel・Microsoft 365 Copilot を使った業務効率化や資料作成のお仕事も受けてきました（例：Copilotの業務検証を支援し、手順書・比較表・報告スライドを納品）。

確定申告の前に、ため込んだ領収書や通帳・カード明細の入力をまとめて頼みたい方には、**「確定申告前の記帳まとめ入力」**もあります（申告書の作成・税務相談は、税理士の業務のため行いません）。
